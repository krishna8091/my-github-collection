# My GitHub Collection

A catalogue of repositories worth revisiting across different subjects. This is an index, not a place to copy every project's source code.

## How to use
- Add each useful repository to the relevant topic's `README.md`.
- Record the original URL, your fork URL (if any), purpose, date added and status.
- Star repositories you only want to bookmark; fork when you need your own copy or plan to contribute.
- Check the original project's licence and contribution rules before reusing code.
